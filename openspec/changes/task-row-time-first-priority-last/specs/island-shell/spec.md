## ADDED Requirements

### Requirement: 任务行统一布局（时间在前，优先级在后）

同一列表内出现的任务行——个人任务行（`PersonalTodoRow`）与日历/提醒行（`MeetingRow`）——SHALL 采用同一套单行视觉模板，按以下从左到右的固定顺序排列元素：

1. **状态字形**：完成绿勾 / 可完成圈 / 未来静态小点，等宽占位。
2. **时间轨**：行首等宽左对齐列，显示该项的有效时间（个人任务取 `effectiveDue`，日历/提醒取起始时间）。时间轨 SHALL 与 `MeetingRow` 使用相同的列宽、字体与对齐，使所有行标题左对齐到同一条竖线。无有效时间的任务 SHALL 保留时间轨占位（留空）而不让标题左移。
3. **标题**：单行，完成态加删除线。
4. **kind 徽章**：仅「提醒 / 日程」类显示，纯任务不显示。
5. **Spacer**：弹性填充。
6. **优先级徽章**：位于行尾（Spacer 之后），是该行最后出现的元数据元素；纯日历事件无优先级则不显示。
7. **悬停操作**：编辑 / 删除等按钮按各自规则在悬停时出现于行尾。

个人任务行 SHALL NOT 再使用「标题 + 第二行元信息」的两行布局，时间 SHALL NOT 出现在优先级之后。本要求仅约束展示顺序与对齐度量，不改变完成、删除、编辑、跳转等任何行为。

#### Scenario: 个人任务行时间在前优先级在后
- **WHEN** 在 Today 或「任务」列表渲染一条有截止时间、优先级为「中」的个人任务
- **THEN** 该行为单行布局，行首时间轨显示截止时间，标题居中，优先级「中」徽章出现在行尾
- **AND** 时间出现在优先级之前，二者不再同处第二行

#### Scenario: 无截止时间的任务仍对齐
- **WHEN** 渲染一条没有有效截止时间的个人任务
- **THEN** 时间轨留空但保留等宽占位，标题与同列表其他行的标题左对齐到同一竖线

#### Scenario: 个人任务行与日历行像素级对齐
- **WHEN** 同一列表中相邻出现一条个人任务行与一条日历/提醒行
- **THEN** 两行的状态字形、时间轨宽度、标题起始位置、行内间距一致，扫读时时间与标题各自成列

#### Scenario: 纯日历事件无优先级
- **WHEN** 渲染一条没有优先级概念的日历事件行
- **THEN** 行尾不出现优先级徽章，其余元素顺序与个人任务行一致
