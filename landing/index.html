一块会变形的黑条

平时它只露一个数字和一个小图标，安静地待在刘海里。 有事发生时它会展开：任务降落、到期提醒、AI 解析、庆祝清空。 鼠标一悬停就拉开成完整面板，移开又收回去。

  • · 悬停展开、移开收回，无需点击
  • · 临近 / 超期分级辉光，余光就能感知

截图即待办

看到要做的事，截一下就进清单

聊天里别人催的、邮件里答应的、会议纪要定的——按 F2 框选， AI 直接读出标题、截止时间和优先级，落成一张「任务降落卡」， 确认即入库。也能 ⌘V 把剪贴板的图直接喂进去。

自动判截止 高 / 中 / 低 优先级 无法识别会如实提示

不只是个待办

AI 晨报 / 晚报

早上理清今天，晚上收个尾

综合优先级和截止，挑出该先做的几件；进行中的工单单列，待办只给计数。 语气像个话不多的同事，不灌鸡汤。

语音速记

⌥Space 说一句

一个全局快捷键，开口说，自动转成待办。快捷键还能自己改键，避免和别的软件撞。

日历时间线

事件、提醒、个人任务，一条线看完

接入 Apple 日历与提醒事项，未来两周的安排和你自己的待办并到同一条时间线上， 当天该处理的自动进「今日」。

接进你已经在用的工具

指派给你的 Jira、待 review 的 PR、@你的 Confluence、收件箱里要紧的邮件， 统一收到刘海，不用来回切。

给写代码的人

你的 agent 跑到哪了，刘海告诉你

挂上 Claude Code / opencode 的 hook，刘海实时显示有几个会话在跑、哪个在等你确认。 一轮跑完弹一张卡，点一下直接跳回那个终端窗口。 不用再守着终端等它问你「要不要继续」。

  • · 运行中 / 等待确认 实时计数
  • · 完成弹卡，点击跳回终端 / iTerm / tmux pane
  • · 子任务完成不打扰，只有整轮结束才提示
